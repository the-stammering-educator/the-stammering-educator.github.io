Innovation Framework

A structured development process from discovery to evaluation and improvement.

Digital innovation projects in this portfolio progress through a defined lifecycle focused on educational relevance and user evidence.

  1. Problem Discovery

    Identify a clear educational, accessibility or operational challenge from practice.

  2. Investigation

    Review affected users, existing workflows, constraints and technical feasibility.

  3. Proof of Concept

    Develop a focused version to evaluate whether the proposed function can work.

  4. Pilot

    Test the tool with an appropriate user group in a realistic educational setting.

  5. Evaluation

    Collect and analyse structured quantitative and qualitative user evidence.

  6. Implementation

    Decide whether to progress, adapt, combine with existing services, or stop.

  7. Improvement

    Refine the tool using ongoing feedback, accessibility checks and context changes.
