BEAT: Bulk Image Alt-Text Generator

Accessibility | Batch processing for educational image descriptions[cite: 1]

Project Summary

BEAT allows staff to upload images in bulk and receive draft alt-text descriptions[cite: 1].

Challenge

Producing alt text for large collections of educational images can require substantial manual effort[cite: 1].

Context

Course slide decks and learning resources often contain numerous visual items[cite: 1]. Without descriptive alt text, screen-reader users encounter information barriers[cite: 1]. Drafting individual descriptions from scratch creates substantial workload for academic teams[cite: 1].

Contribution

My contribution focused on[cite: 1]:

  • Concept development[cite: 1]
  • Workflow design[cite: 1]
  • Product evaluation[cite: 1]
  • Pilot support[cite: 1]
  • User research[cite: 1]

Solution

The tool supports batch processing so staff can review draft descriptions rather than starting each description from a blank page[cite: 1].

Design Approach

Staff upload batches of image files through a direct web interface[cite: 1]. The system processes the image collection and displays an editable list of draft descriptions that staff review, amend and export[cite: 1].

Key Functions

  • Bulk image upload[cite: 1]
  • Draft alt-text generation[cite: 1]
  • Batch processing[cite: 1]
  • Downloadable outputs[cite: 1]

Project Screenshot

Evaluation

Evaluation examined whether presenting draft descriptions accelerated the alt-text creation process and helped staff identify missing descriptions[cite: 1].

Limitations

Generated alt text requires human review[cite: 1]. The tool does not guarantee accessibility compliance, contextual accuracy or suitability for every learner and image[cite: 1]. It does not automatically meet WCAG requirements[cite: 1].

Lessons Learned

Automated drafts provide a helpful starting structure, but discipline-specific diagrams, graphs and instructional charts always require subject-expert review to ensure pedagogical accuracy[cite: 1].

Next Steps

Further development would depend on user need, evaluation evidence, technical feasibility and available institutional support[cite: 1].
