VoiceCrafter: Text to Speech

Accessibility | Speech synthesis for flexible learning access[cite: 1]

Project Summary

A text-to-speech tool that allows users to convert text and uploaded documents into spoken English[cite: 1].

Challenge

Written study materials are not equally accessible to all students, particularly those who rely on listening or benefit from multi-modal engagement[cite: 1].

Context

The project explored flexible access to educational content for users who prefer or require audio formats[cite: 1]. Providing practical conversion options supports inclusive study workflows[cite: 1].

Contribution

My contribution focused on[cite: 1]:

  • Concept development[cite: 1]
  • Accessibility design[cite: 1]
  • User experience design[cite: 1]
  • Product evaluation[cite: 1]
  • Educational resource development[cite: 1]

Solution

A dedicated tool converting text inputs and standard file formats into downloadable spoken audio with controllable voice settings[cite: 1].

Design Approach

The user interface provides controls over voice styles, pacing, and Speech Synthesis Markup Language tags so outputs can be tuned for instructional clarity[cite: 1].

Key Functions

  • Manual text input[cite: 1]
  • Word document input[cite: 1]
  • PDF input[cite: 1]
  • Voice selection[cite: 1]
  • Accent options[cite: 1]
  • SSML controls[cite: 1]
  • Speaking-rate controls[cite: 1]
  • Audio download[cite: 1]

Project Screenshot

Evaluation

Testing assessed the clarity of generated speech across academic terminology and evaluated audio export reliability with uploaded documents[cite: 1].

Limitations

Generated audio should be checked for pronunciation, meaning and suitability before distribution[cite: 1]. Technical jargon and non-standard notation require verification[cite: 1].

Lessons Learned

Standard synthesis handles narrative text effectively, but complex academic terminology requires explicit pronunciation markup using SSML to prevent reading errors[cite: 1].

Next Steps

Further development would depend on user need, evaluation evidence, technical feasibility and available institutional support[cite: 1].
