CiteRite

Assessment and Feedback | Audience: Tutors and learners | Referencing formatting analysis

Project Summary

A reference-format and validity support tool that provides analysis of in-text citations and bibliographies.

Challenge

Students frequently struggle to apply academic referencing conventions accurately, while tutors spend substantial time marking repetitive formatting errors.

Context

Mastering citation conventions is an essential academic skill. Formative support before assignment submission helps learners identify structural discrepancies between their citations and bibliography lists.

Contribution

My contribution focused on:

  • Concept development
  • Educational design
  • Feedback design
  • Workflow design
  • Product evaluation

Solution

A formative tool providing diagnostic feedback on citation structure, bibliography layout, and matching between body text and reference lists.

Design Approach

The system accepts direct text inputs or uploaded draft files. It parses citation instances, evaluates them against standard style criteria, and outputs an itemised feedback report.

Key Functions

  • Text input
  • Word document upload
  • PDF upload
  • In-text citation analysis
  • Reference-list analysis
  • Formatting checks
  • Bibliography feedback
  • Downloadable feedback

Project Screenshot

Evaluation

Evaluation focused on the parsing accuracy of in-text citations and the clarity of generated feedback notes for learners.

Limitations

CiteRite is a formative referencing-support tool. It is not a plagiarism detector and should not make formal academic misconduct decisions.

Lessons Learned

Automated checks help students spot missing references, but learners need clear explanations alongside error tags to improve their referencing habits over time.

Next Steps

Further development would depend on user need, evaluation evidence, technical feasibility and available institutional support.
